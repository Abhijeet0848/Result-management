# Contributing to Online Result Management System

Thank you for your interest in contributing! 🎉

## How to Contribute:

1. **Fork the Repository** on GitHub.
2. **Clone your fork**:
   ```bash
   git clone https://github.com/your-username/Online-result-system-perfect.git
   cd Online-result-system-perfect
   ```
3. **Create a new branch**:
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. **Make your changes**:
   - Ensure all PHP files pass syntax checks (`php -l filename.php`).
   - Use parameterized SQL queries (`pg_query_params`).
   - Avoid committing any `.env` or sensitive credentials.
5. **Commit and Push**:
   ```bash
   git commit -m "Add new feature: description"
   git push origin feature/your-feature-name
   ```
6. **Submit a Pull Request** on GitHub!
